Task 3: Answer the Guide Questions 
1. What is the difference between readyState and status in XMLHttpRequest? 
   - readyState is a number from 0 up to 4 that shows how far along the request is. 
     It just tells you the step we're at, not if it actually worked or not.
     0 = haven’t started yet
     1 = connected already
     2 = the request was sent out
     3 = still waiting/loading the reply
     4 = all done — good to go
   - status is the HTTP result code from the server. 
     It tells you straight up if the request succeeded or failed.
     200 = okay / it worked
     404 = can’t find what you’re looking for
     500 = something went wrong on the server’s end

2. How can you make the request asynchronous? 
   - Set the third parameter in xhr.open() to true:
     xhr.open("GET", "https://...", true);

     When you set it to true → it’s asynchronous. It keeps running everything else normally, and just deals with the response whenever it actually shows up later.
     If you set it to false → it’s synchronous. The browser totally freezes, you can’t click or do anything else until the whole request finishes and comes back.

3. Why is asynchronous communication recommended for web applications?
   - Async requests keep the page responsive, never freeze the browser, let multiple requests run together, update content without reloading, and give the smooth, fast experience most sites use today.
